# DJI Mic Mini

[DJI Mic Mini](https://www.dji.com/mic-mini) is a wireless
[microphone](/wiki/audio_%28general%29.md#microphones) system consisting of one or
two transmitters (TX) and a receiver (RX).
It can be used with smartphones, cameras and computers.
The transmitters can also connect directly to smartphones via [Bluetooth](/wiki/bluetooth.md)
without the receiver.

## Setup

The firmware can be updated and [microphone](/wiki/audio_%28general%29.md#microphones) settings can
be configured using the [DJI Mimo app](https://www.dji.com/mimo).
The app is available for [Androids](/wiki/android.md) Google Play Store and iOS App Store.

## Usage

This section addresses the usage of DJI Mic Mini.

### Connecting via Receiver

The receiver can be connected to a smartphone via USB-C or to a camera via its 3.5mm audio output.

The transmitters are usually paired with the receiver by default.
In this mode, the LED lights up green.
If the LED does not light green, a transmitter can be switched into receiver mode by pressing its
link button twice.

To pair the devices manually, hold the link buttons on both the transmitter and receiver for
approximately 2 seconds.
A solid green LED indicates a successful connection.

### Connecting via Bluetooth

The transmitter can also be used without the receiver by connecting directly to a
[Bluetooth](/wiki/bluetooth.md) device.

If the LED of the transmitter does not light blue, a transmitter can be switched into Bluetooth mode
by pressing its link button twice.

To pair the transmitter, hold its link button for approximately 2 seconds and select the DJI Mic
Mini in the Bluetooth settings of the other device.
A solid blue LED indicates a successful connection.

Note that not all apps support direct Bluetooth audio input from the transmitter.
Some apps, such as [Signal](/wiki/signal.md), may continue using the smartphone's internal
[microphone](/wiki/audio_%28general%29.md#microphones) even when the transmitter is connected.
Using the USB-C receiver is generally more reliable and compatible with more apps.

### Switching between Mono and Stereo

The receiver can switch between mono and stereo mode by pressing its link button twice.

In Mono mode the LED lights green.
In this case both transmitters are mixed into one audio channel.
This is recommended when using only one transmitter.

In Stereo mode the LED lights cyan.
In this mode the transmitters are recorded on separate left and right channels.
This is useful when using two transmitters.

### Noise Cancellation

Noise cancellation can be enabled or disabled by pressing the transmitter's power button once.
A yellow LED indicates that noise cancellation is enabled.
