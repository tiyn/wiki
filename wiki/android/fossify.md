# Fossify

[Fossify](https://www.fossify.org/) is a free and open-source software project that develops a
collection of privacy-focused applications for [Android](/wiki/android.md).
The applications are ad-free and are designed to work primarily with local data and Android system
services.
Fossify originated as a fork of the discontinued
[Simple Mobile Tools](https://github.com/SimpleMobileTools) project.

## Setup

Fossify applications are available individually for Android.
An overview of the available applications can be found on the
[official website](https://www.fossify.org/apps/).

The applications are generally available through [F-Droid](/wiki/android/f-droid.md) and the
[Google Play Store](/wiki/android.md#app-store).
