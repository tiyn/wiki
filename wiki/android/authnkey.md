# Authnkey

[Authnkey](https://github.com/mimi89999/Authnkey) is a free and open-source credential provider for
[Android](/wiki/android.md) that helps [FIDO2](/wiki/fido2.md) security keys work properly with
passkeys over NFC or USB.
It addresses limitations in Android's built-in FIDO2 support, including PIN verification and stored
passkeys, and does not require Google Play Services.
It requires Android 14 or newer and a compatible FIDO2 security key.

## Setup

Authnkey is available on [F-Droid](/wiki/android/f-droid.md) in a package called
[pl.lebihan.authnkey](https://f-droid.org/packages/pl.lebihan.authnkey/).
