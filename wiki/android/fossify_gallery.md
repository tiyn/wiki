# Fossify Gallery

[Fossify Gallery](https://www.fossify.org/apps/gallery/) is a free and open-source gallery
application for [Android](/wiki/android.md) developed as part of
[Fossify](/wiki/android/fossify.md).
It can be used to browse, organize and edit photos and videos stored on the device.

## Setup

On [Android](/wiki/android.md) Fossify Gallery is available on [F-Droid](/wiki/android/f-droid.md)
in a package called [Fossify Gallery](https://f-droid.org/packages/org.fossify.gallery/).

Additionally, it is available on the [Google Play Store](/wiki/android.md#app-store) in a package
called [Fossify Gallery](https://play.google.com/store/apps/details?id=org.fossify.gallery).

## Usage

This section addresses the usage and configuration of Fossify Gallery.

### Exclude Folders

Folders that should not be displayed by Fossify Gallery can be excluded without modifying or
renaming them.

After navigating to the settings and selecting `Manage excluded folders` the respective folder can
be added to the list of excluded folders.
Over the same menu excluded folders can be re-included.
Excluding a folder should be preferred over hiding it if the folder should simply not be displayed
by Fossify Gallery.
