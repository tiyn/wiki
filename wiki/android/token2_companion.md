# Token2 Companion App

The
[Token2 Companion App](https://play.google.com/store/apps/details?id=com.token2.companion&hl=de&pli=1)
is an [Android](/wiki/android.md) application for managing compatible
[FIDO2 security keys](/wiki/fido2.md).
It can be used to manage TOTP profiles and FIDO settings via NFC or USB.

## Setup

On [Android](/wiki/android.md) the app is available in the
[Google Play store](/wiki/android.md#app-store) as
[Token2 Companion App](https://play.google.com/store/apps/details?id=com.token2.companion&hl=de&pli=1).
