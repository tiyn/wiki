# Web

The web – or correctly World Wide Web – is a system for publishing and accessing linked content over
the internet.
Web content is commonly structured using [markup languages](/wiki/markup_language.md), especially
[HTML](/wiki/markup_language.md#html), and can be accessed interactively using
[web browsers](/wiki/web_browser.md) or automatically using [web crawlers](/wiki/web_crawling.md).
