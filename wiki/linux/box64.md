# Box64

[Box64](https://github.com/ptitSeb/box64) is an emulator that allows running x86_64
[Linux](/wiki/linux.md) applications on ARM64 and other supported architectures.

## Setup

On most [Linux](/wiki/linux.md) systems, Box64 can be installed using the `box64` package.

## Usage

This section addresses the usage of Box64.

### Start a Program

To execute an x86_64 Linux binary, the following command can be used.
However, not all applications are compatible, and additional libraries may be required.

```sh
box64 ./program
```
