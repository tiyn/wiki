# Programming Language

A programming language is a language for expressing computer programs.

## List of Programming Languages

The following is a list of programming languages that are featured in this wiki.

- [C](/wiki/programming_language/c.md) is a compiled, procedural language for low-level systems
  programming.
- [Go](/wiki/programming_language/go.md) is a compiled, imperative language with built-in
  concurrency support.
- [Nim](/wiki/programming_language/nim.md) is a compiled, multi-paradigm language with Python-like
  syntax.
- [Python](/wiki/programming_language/python.md) is a dynamically typed, multi-paradigm scripting
  language.
- [Rocq](/wiki/programming_language/rocq.md) is a proof assistant with a dependently typed
  functional language.
- [Rust](/wiki/programming_language/rust.md) is a systems programming language with ownership-based
  memory safety.
- [VHDL](/wiki/programming_language/vhdl.md) is a concurrent hardware description language for
  digital circuits.
- [Viper](/wiki/programming_language/viper.md) is an intermediate verification language based on
  permissions.
